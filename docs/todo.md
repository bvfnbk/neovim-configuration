# Managing Todos

This configuraton contains a plugin to manage todos: _Dooing_. It allows management of global and project-specific
todos.

## Keymap


| Shortcut | Description           |
| ---      | ---                   |
| `i`      | Create new todo.      |
| `e`      | Edit todo item.       |
| `p`      | Edit todo priorities. |
| `x`      | Toggle item status.   |
| `d`      | Delete current Todo.  |
| `?`      | Show help window.     |

> [!note]
>
> The current todo item can only be deleted if its status is toggled to 'done' before.
